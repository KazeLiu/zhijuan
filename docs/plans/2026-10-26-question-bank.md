# 题库实现计划

依据：`docs/question-bank-feature.md`。在现有 Nuxt 项目中完成题库到组卷的完整入口，旧 AI 出题、答题、判分和答案公开规则继续可用。

## 实施顺序与完成条件

- [x] 共享契约与迁移：追加 004，题库与引用分表；场次副本保留来源 ID 和版本，旧题默认无来源。
- [x] 题库服务：内容和出处校验、精确重复、审核状态、版本冲突、从场次整批入库；所有写操作短事务。
- [x] 组卷与统计：随机替换和手动追加、同事务挂载资料与换引用、整数重新配分；批量读取可比作答、姓名去重、人工分优先、筛选后分页。
- [x] 管理界面：共用题目内容表单、题库列表/详情/审核/编辑、知识点与来源筛选、场次组卷与勾选入库，保留未保存内容。
- [x] 相邻集成：资料库引用计数和删除保护、侧栏与窄屏入口、已有场次整体保存来源保留。
- [x] 静态自查与文档：核对接口、迁移、调用者、错误恢复和差异，更新真实使用说明。

## 验证与边界

本次不新增、修改或运行测试，不构建、不启动应用、不进行浏览器或模型验收；使用源代码、调用关系与 `git diff --check` 自查。数据库迁移和实际页面交互由用户试用确认。当前 README 有用户修改，只增量更新题库相关段落。保留现有运行服务与真实数据，不主动执行迁移或清库；提交与推送按用户后续授权执行。

迁移只追加表、索引与可空来源列，旧数据不回填为题库。新版本运行后不要直接用旧版程序继续写入新增题库数据；回退部署需保留升级前的数据备份。
